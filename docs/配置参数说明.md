# 部署参数与固定约定

云端连接不再使用代码内的默认地址。修改 device-agent.cloud.conf 后重启程序即可，不接收命令行参数。

| 配置项 | 用途 |
| --- | --- |
| host / port | 云端 MQTT 域名或 IP、端口，必填 |
| device | 设备码，必填 |
| enroll-url / model | 注册接口、注册型号；启用注册时型号必填 |
| enrollment-key | 注册码；已有 Token 缓存时复用缓存 |
| state-dir | 命令状态与 Token 缓存目录，必填 |
| work-dir | 临时日志包目录，必填 |
| sources-config | 日志源 JSON 文件；填写后从文件读取来源 |
| log-file | Agent 自身日志文件；留空则关闭文件输出，Android 仍输出 Logcat |
| https-ca | 注册和上传使用的 CA 文件；Android 包中配置 ca-bundle.pem |
| token-file | 可选，自定义 Token 文件位置 |
| ca | 可选，MQTT TLS CA 文件 |

相对路径以配置文件所在目录为基准。日志源的 path 可分别指向任意可读目录，支持绝对路径和相对路径。allowed-root 已废弃，旧配置仍可读取，但会提示忽略。不会自动创建业务日志目录。文件匹配字段为 file_patterns。

示例：

```json
{
  "log_sources": [
    {"source_id": "business", "path": "/storage/emulated/0/nxlog", "recursive": true, "file_patterns": ["*.log", "*.txt"]},
    {"source_id": "camera_sdk", "path": "/data/vendor/logagent/business-logs/sdk", "recursive": true, "file_patterns": ["*.log", "*.txt"]}
  ]
}
```

## 仍然固定的内容

以下项目本次保留在代码中，没有宣称全部已配置化：

- 配置入口：Ubuntu 从当前目录读取 device-agent.conf；Android 从 /data/vendor/logagent/device-agent.conf 读取。Android 入口目录可通过 CMake 的 DEVICE_AGENT_ANDROID_DATA_DIR 在构建时修改。配置文件必须有一个确定的查找入口。
- Android Logcat 标签 DeviceAgent、SIGINT/SIGTERM 退出行为。
- MQTT 主题 v1/d/<设备码>/up、down，以及兼容业务注册主题 local/v1/<设备码>/biz；属于当前云端协议约定。
- MQTT keepalive 30 秒；注册连接超时 5 秒、总超时 15 秒；上传连接超时 5 秒、总超时 30 秒。
- 最多保留 100 条命令结果；单次最多 10000 个文件；日期区间最长 31 天；来源数量和匹配规则数量也有内部上限。
- 文件名日期由 filename_date_formats 配置（默认 %Y-%m-%d），按 UTC+8 解释；文件内容不解析。跳过符号链接和空文件。
- 软件版本字符串 0.1.0、压缩包及清单格式、JSON 协议字段、Token 缓存默认命名规则。

这些协议约定与内部限制可按后续需求继续配置化；更换云端地址或日志目录已经无需修改代码。实际读取还受 Android 挂载命名空间、Linux 文件权限及 SELinux 策略限制。

配置解析失败发生在文件日志打开之前，因此看终端或 Android Logcat 中的 FATAL；配置成功后按 log-file 输出文件日志。


每个 `log_sources` 可配置 `filename_date_formats`，按顺序尝试识别文件名中的日期：

```json
"file_patterns": ["*.txt", "*.log"],
"filename_date_formats": ["%Y-%m-%d.txt", "%Y%m%d.txt", "app_%d-%m-%Y.log"]
```

分别匹配 `2026-10-21.txt`、`20261021.txt`、`app_21-10-2026.log`，也支持文件名前缀。`%Y`、`%m`、`%d` 必须各出现一次，表示四位年、两位月、两位日；`%%` 表示字面百分号，其余字符按字面匹配。最多 16 个格式，每个最多 256 字节。省略或空数组默认识别 `%Y-%m-%d`。文件仍需匹配 `file_patterns`；日期按北京时间解释，无效日期跳过，最新文件模式仍按修改时间选择。修改配置后重启 Agent。
