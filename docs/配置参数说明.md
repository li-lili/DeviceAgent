# Android 配置参数

入口文件 device-agent.conf 可用 environment=cloud 选择同目录 device-agent.cloud.conf。
device：业务 SN，必须与云端已绑定公钥对应；程序不会自动读取 Android 属性。
private-key：已有配套 PEM 私钥文件路径，Agent 只读，不生成密钥。
identity-dir：测试阶段身份目录，内含 identity.json（sn、public_key）与 priv.pem；启用后 device、private-key 可省略，写 device 时必须与 sn 一致，私钥必须与 public_key 配对。
enroll-url：HTTPS 签名换 Token 地址。
https-ca：受信公共 CA bundle；不得使用 localhost CA 或关闭验证。
host、port：云端 MQTT；username 默认使用 SN，Token 作为密码。
ca：仅用于 MQTT TLS，与 HTTPS 的 https-ca 分开配置。
state-dir：状态和 Token 根目录；Token 默认位于 tokens/SN.token。
work-dir：临时任务目录。log-file：运行日志文件。
sources-config：业务日志来源 JSON；首次联调应仅允许独立空测试目录。
token、token-file 优先于签名 enroll；要验证设备端签名，应使用新的隔离状态目录，不删除已有 Token。
相对路径以配置文件所在目录为基准。SN、公钥、私钥和 Token 不随包分发。
